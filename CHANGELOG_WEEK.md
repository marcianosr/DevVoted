# DevVoted - Weekly Update
**Week of October 18-24, 2025**

## ✨ New Features

- **Extended Game Rounds**: Rounds now include 5 polls instead of 3, giving you more chances to prove your dev knowledge and rack up points.

- **Victory Conditions**: Added a proper win state! Complete your runs successfully and get the celebration you deserve with a dedicated end screen.

- **Poll Encyclopedia (Polldex)**: Track which questions you've encountered and how many times you've answered each one. Perfect for completionists who want to see everything the game offers.

- **Run Reset Anytime**: Stuck or want to try a different strategy? Reset your current run at any time without losing your overall progress.

- **Smarter Shop Management**: The shop now only increases rebuild costs when you actually progress through Continuous Integration gates, making resource management more strategic.

- **Enhanced Configuration System**:
  - Improved bonus calculations with better mathematical foundations
  - More granular tracking with decimal percentage coverage
  - Random configuration generation with comprehensive test coverage

## 🔧 Improvements

- **Better Button States**: Shop buttons now properly disable when you're out of storage space, preventing accidental clicks.

- **Clearer Terminology**: Changed "reroll" to "rebuild" in the shop for more intuitive understanding of what the action does.

- **Refined Scoring System**: Complete overhaul of how configurations and scores are calculated, making progression feel more rewarding and balanced.

- **Code Quality**: General cleanup and refactoring for better maintainability.

## 🐛 Fixes

- **Retroactive Config Bonus Bug**: Fixed a critical issue where configuration bonuses weren't being applied correctly to past performance.

- **End Screen Display**: Resolved issue where the end screen wasn't showing up properly after completing a run.

- **User Service Reliability**: Added proper error handling to prevent crashes when user operations fail.

- **Test Suite**: Fixed failing tests to ensure everything works as expected.

---

*These updates focus on making DevVoted more engaging with longer rounds, clearer win conditions, and better progression tracking. The shop and configuration systems have been refined for a more strategic experience.*
