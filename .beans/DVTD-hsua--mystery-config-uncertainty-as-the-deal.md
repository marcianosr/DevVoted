Unknown/mystery package mechanics for configs with hidden modifiers

## Concept
Rather than just a cheaper random config, make uncertainty itself the value prop. Mystery packages contain configs with hidden properties that resolve on purchase/use.

## Core Mechanic
Mystery Package (96 KB)
- Contains one config not currently offered
- Price reflects the risk/opportunity

## Possible Guarantees (Design Choices)
- At least Uncommon rarity
- Guaranteed config you don't own yet
- Random level 2-4 config
- Random category
- Could contain something worth significantly more (upside risk)

## Variants to Explore
**npm install ???**
- Random config from any rarity tier

**npm install --legacy-peer-deps**
- Random upgraded config BUT includes a hidden downside (malus modifier)

**Unverified Package**
- 50% cheaper, but config starts with hidden modifier/check until installed/verified

## Design Notes
- Uncertainty creates engagement through discovery
- Hidden modifiers (positive and negative) add replay value
- Naming via npm metaphors is fun (legacy-peer-deps = risk, unverified = trust)
- Lower unlock bar than Marketplace
- Could introduce earlier as a reroll mechanic variant
