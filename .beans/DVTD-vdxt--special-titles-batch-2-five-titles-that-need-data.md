**What:** Add YOLO Deploy, rm -rf node_modules, Friday Deploy, Cache Me If You Can and Git Blame as special titles.

**Why:** They complete the roster asked for alongside batch 1, but each reads something a single run step cannot see.

## Done when
- [ ] Each of the five can be earned
- [ ] Each open question below has an answer recorded in an ADR
- [ ] The wiki and changelog name them

## Notes
- YOLO Deploy: leave the shop unchanged, then clear the next gate HEALTHY. Needs a run flag kept until the next close. Open: which shop presses count as a change (rebuild, lock-offer, incident buy)? Exactly HEALTHY or HEALTHY and better?
- rm -rf node_modules: sell or drop five configs in one run. Needs a per-run counter. Open: do peel strips count as drops; are decay and lapse losses excluded?
- Friday Deploy: clear an audited gate on a Friday. Needs the date passed into metric detection. Open: server date or player timezone; the day the gate is cleared or entered?
- Cache Me If You Can: answer a recurring poll 5 times. Needs a count of past answers to the same poll. Open: session only or calendar too; must they be correct?
- Git Blame: file an incident against somebody who filed one against you. Needs an incidents query at filing. Open: do queued incidents count, or only landed ones; any time or a window?
