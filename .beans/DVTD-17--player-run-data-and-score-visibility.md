Players currently lack visibility into their run history and score breakdown. Improve data transparency:

- Run history: past runs with gate reached, polls answered, configs used, coverage per category
- Score breakdown per poll (base + round scaling + streak bonus)
- Coverage progression over time within a run
- Stats comparison across runs (e.g. best gate reached, highest coverage in a category)
- Show more run info on progress page: rerolls used, configs bought, correct/incorrect counts
