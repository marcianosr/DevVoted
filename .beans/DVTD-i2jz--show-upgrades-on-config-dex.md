Display config upgrade levels and progression in the config dex/encyclopedia so players can track which configs they've upgraded

## Config Dex Display

### Upgrade Level Indicator
- [ ] Show current upgrade level (e.g., "Lvl 5/10") on each config card
- [ ] Visual progress bar or star rating to indicate level
- [ ] Color-code by rarity: common/uncommon/rare/legendary
- [ ] Highlight maxed-out configs (Lvl 10)

### Config Details View
- [ ] Click config to see detailed stats and upgrade progress
- [ ] Show power scaling by level (e.g., "coverage 2x → 2.2x → 2.4x...")
- [ ] Display current and next level bonuses side-by-side
- [ ] Show cost/requirement to reach next level

### Progression Visualization
- [ ] Timeline or chart showing upgrade path to max
- [ ] Milestone markers (e.g., "Lvl 5 = halfway")
- [ ] Est. runs needed to upgrade (if upgrade currency based on play)
- [ ] Achievement/mastery indicator

### Collection View
- [ ] Filter configs by upgrade level (All, Lvl 1, Lvl 5+, Maxed)
- [ ] Sort options: by rarity, by upgrade level, by power
- [ ] Statistics: "5/20 configs maxed", "avg level 3.2"
- [ ] Completion percentage for motivational display

## Interaction
- [ ] Tap/click config to see upgrade details
- [ ] Upgrade button visible when upgradeable
- [ ] Confirmation before spending upgrade currency
- [ ] Toast/feedback showing upgrade complete
