**What:** Five names from the game that came before DevVoted are kept on ice because nothing in the game today can award them.

**Why:** They are good names and deleting them loses them; writing a mechanism just to house them would be the tail wagging the dog.

## Done when

- [ ] Each parked name says what the game would need before it could be earned
- [ ] The names are found again when that thing is built, not rediscovered by accident

## Notes

**Speed Demon, Lucky number 7, No Hurry.** All three rank players against each other on one shared poll: first to answer, seventh, last. The data would support it, since the day's poll sequence is global and every answer is stamped, but nothing computes such a rank, no index exists for it, and a run deals a private sequence, which is the wrong frame for a race. If a shared daily surface or a seasonal event ever lands, these work as written.

Speed Demon has a solo re-cut available whenever it is wanted: how long a player took is already stored per answer, so "answered fast" is a threshold on your own clock rather than a race. That is a different award wearing the same name, so it is a decision, not a fallback.

**The Next Generation, Next Level.** Both are Next.js, and there is no Next.js category. Adding one reaches polls, configs, both leader boards and the collection screen, which is far past what two names justify.
