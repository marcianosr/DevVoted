After surviving a gate where the player chose double-pick (DVTD-k9mw), reward them with a slot removal — permanently delete one slot from the pipeline.

This is the only mechanic in the game that reduces pipeline complexity. Every other upgrade card adds or upgrades. Makes it rare, earned, and strategically significant.

Player picks which slot to remove, creating a meaningful choice: which slot is currently hurting the build most?

- Does slot removal happen immediately after the gate or is it banked for later?
- Is there a minimum pipeline size below which slot removal is blocked?
