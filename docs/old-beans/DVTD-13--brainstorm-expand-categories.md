Currently the game has 11 categories. This brainstorm should decide how to expand the category set to include more specific framework and platform topics.

Ideas so far:
- Vue.js
- Next.js
- TanStack (Query, Router, etc.)
- Browser APIs / Web Platform
- Potentially others: Svelte, Astro, Node.js specifics, CSS/animations, tooling (Vite, Webpack)

Questions to answer:
- How many categories is too many? Does the roguelike mechanic scale?
- Should frameworks be sub-categories under a parent (e.g. "Frameworks > Vue")?
- How does this affect category weight/coverage mechanics in runs?
- Minimum viable question count per new category before it's playable?
