The current experience of approaching a CI gate lacks tension. Make it feel like a boss encounter is coming:

- Visual/UI indicator that a gate is approaching (e.g. countdown, warning banner)
- Tease the gate requirement as it gets closer: 'The Git Gatekeeper is approaching… you need 30% in Git'
- Atmosphere shift: color change, animations, sound design
- Progress bar or countdown showing X polls until the gate
- Dramatic entrance when the gate actually triggers
- Show a summary of what the player needs before the gate poll
